# סורק חשבוניות (doc-scanner)

אתר PWA אישי שהופך צילום של חשבונית ל-PDF, בלי פרסומות ובלי מנוי. מיועד לעבוד באנדרואיד ובאייפון (בעלי ואשתי).
כל העיבוד נעשה בתוך הטלפון, שום דבר לא נשלח לשרת.

## מצב נוכחי (21.10.2026)
- גרסה ראשונה בנויה ונבדקה בדפדפן במחשב עם תמונה סינתטית: זיהוי פינות, יישור, שיפור, יצירת PDF עובדים.
- **לא נבדק עדיין:** מצלמה אמיתית, התקנה על מסך הבית, שיתוף לוואטסאפ, שימוש בלי אינטרנט (Service Worker לא נרשם בדפדפן הבדיקה).
- **לא מאורח עדיין.** צריך כתובת HTTPS כדי לפתוח בטלפון. Netlify חסום מהמשרד.

## קבצים
- `index.html` - המבנה והעיצוב (3 מסכים: בית, כוונון פינות, תוצאה)
- `app.js` - כל הלוגיקה: זיהוי דף (OpenCV), יישור, שיפור, PDF (jsPDF), שיתוף
- `sw.js` - Service Worker לשימוש בלי אינטרנט
- `manifest.webmanifest` ואייקונים - להתקנה על מסך הבית

## איך מריצים מקומית
```
python -m http.server 8765 --bind 127.0.0.1
```
ואז לפתוח http://127.0.0.1:8765/index.html בדפדפן. (צריך אינטרנט בפעם הראשונה בשביל OpenCV ו-jsPDF.)

## אפשרויות אירוח (במקום Netlify)
- GitHub Pages (דורש חשבון גיטהאב ומאגר ציבורי)
- Cloudflare Pages
- Vercel
- שרת מקומי בבית + כתובת HTTPS (מסובך יותר)

## הערות / החלטות
- הצילום דרך מצלמת הטלפון הרגילה (`<input capture>`), לא מצלמה בתוך האתר.
- הספריות מקומיות בתיקיית `lib/` (OpenCV `@techstark/opencv-js@4.10.0-release.1`, כ-10MB, ו-jsPDF 2.5.1), נשמרות ב-Service Worker. האתר לא תלוי באינטרנט אחרי הטעינה הראשונה. (עודכן 24.10.2026, עדיין לא נבדק בדפדפן.)
- אם האתר לא מספק, התוכנית היא לבנות אפליקציית אנדרואיד עם ML Kit Document Scanner (חינמי, אנדרואיד בלבד).
- האייקון זמני.
